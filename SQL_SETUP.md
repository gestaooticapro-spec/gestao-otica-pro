# Setup do Banco de Dados para Nuvem Fiscal

Execute os comandos abaixo no Editor SQL do Supabase para criar as tabelas necessárias.

## 1. Tabela `company_settings`
Armazena as configurações da empresa emissora (CNPJ, Endereço, Credenciais NFS-e).

```sql
create table if not exists company_settings (
  id bigint generated by default as identity primary key,
  organization_id uuid references auth.users(id) not null,
  cnpj text,
  cpf_cnpj text,
  razao_social text,
  nome_fantasia text,
  logradouro text,
  numero text,
  complemento text,
  bairro text,
  codigo_municipio_ibge text,
  cidade text,
  uf text,
  cep text,
  inscricao_estadual text,
  regime_tributario text, -- '1' para Simples Nacional
  nfse_login text,
  nfse_password text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Opcional: Índice para busca rápida por organization_id
create index if not exists idx_company_settings_org on company_settings(organization_id);
```

## 2. Tabela `fiscal_invoices`
Armazena o histórico de notas fiscais emitidas.

  xml_url text,
  pdf_url text,
  error_message text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Opcional: Índice para busca rápida por nuvemfiscal_uuid (usado no webhook)
create index if not exists idx_fiscal_invoices_uuid on fiscal_invoices(nuvemfiscal_uuid);
```

## 3. Políticas RLS (Row Level Security) - Sugestão
Se você usa RLS, lembre-se de adicionar políticas para permitir que os usuários leiam/escrevam seus próprios dados.

```sql
alter table company_settings enable row level security;
alter table fiscal_invoices enable row level security;

create policy "Users can view their own company settings"
on company_settings for select
using (auth.uid() = organization_id);

create policy "Users can update their own company settings"
on company_settings for update
using (auth.uid() = organization_id);

create policy "Users can insert their own company settings"
on company_settings for insert
with check (auth.uid() = organization_id);

create policy "Users can view their own invoices"
on fiscal_invoices for select
using (auth.uid() = organization_id);

create policy "Users can insert their own invoices"
on fiscal_invoices for insert
with check (auth.uid() = organization_id);

create policy "Users can update their own invoices"
on fiscal_invoices for update
using (auth.uid() = organization_id);
```
